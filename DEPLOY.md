# Как правильно выложить сайт на Vercel 🐋

Код и продакшн-сборка проверены и работают: `next build` проходит без ошибок,
все страницы (`/`, `/about`, `/music`, `/release`, `/links`) отдают 200 и не имеют
ошибок в консоли браузера на десктоп-разрешении. Если после деплоя сайт «не открывается»
— проблема в способе деплоя, не в коде.

## ❌ Так делать нельзя: перетаскивание папки в браузере

Vercel принимает drag-and-drop только для **статичных** файлов (html/css/картинки).
Если перетащить туда папку с исходниками Next.js — задеплоится «мусор»: сайт покажет
`404 NOT_FOUND` или пустую страницу. Это самая частая причина «закинул — не открывается».

## ✅ Способ 1 — через GitHub (рекомендую)

1. Залей весь проект на GitHub (убедись, что в репозитории лежат `package.json`,
   `next.config.ts`, папки `src/` и `public/`, `bun.lock`).
2. Зайди на [vercel.com/new](https://vercel.com/new) и импортируй репозиторий.
3. Ничего не меняй в настройках: Vercel сам определит Next.js. Build command и output
   трогать не нужно.
4. Нажми **Deploy** и жди окончания сборки (смотри вкладку «Building» — там будут логи).

## ✅ Способ 2 — через консоль (CLI)

Выполняй **из корня проекта** (там, где лежит `package.json`), а не из папки выше:

```bash
npm install -g vercel
vercel          # первый раз спросит логин и создаст проект
vercel --prod   # деплой в продакшн
```

Если запустить `vercel` из другой папки — задеплоится не то, и сайт не откроется.

## Если всё равно не открывается — чек-лист

1. **Открой логи сборки**: Vercel → твой проект → вкладка *Deployments* → клик на
   деплой → *Building*. Если там красная ошибка — сайт не собрался, деплоя нет.
2. **Node.js**: в настройках проекта (*Settings → Node.js Version*) должно быть
   **20.9 или новее** (лучше 22.x). В `package.json` уже добавлено `engines.node >= 20.9`.
3. **Framework preset**: *Settings → Build & Output Settings* → Framework preset =
   **Next.js**, Build Command = `npm run build` (или пусто = автодетект).
4. **Файлы**: проверь, что в деплой попали `src/`, `public/`, `package.json`,
   `next.config.ts`. Папки `node_modules` и `.next` заливать не нужно.
5. **Кэш браузера**: если раньше сайт уже открывался с ошибкой — обнови страницу
   с очисткой кэша (Ctrl+Shift+R) или в инкогнито.

## Технические детали (уже сделано в проекте)

- `package.json` → `"engines": { "node": ">=20.9.0" }` — Vercel не соберёт проект
  на слишком старом Node.
- Скрипт `build` защищён: копирование файлов для локального запуска
  (`cp -r … || true`) больше не может уронить сборку на Vercel.
- База данных проекту не нужна: `DATABASE_URL` из `.env` нигде не используется,
  на Vercel переменные окружения можно не настраивать.
